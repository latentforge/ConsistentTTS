# PromptTTS++

PromptTTS++ controls speaker identity in prompt-based text-to-speech using natural language descriptions: a GST-style reference encoder and mixture density network (MDN) predict a style embedding from the prompt and/or reference mel-spectrogram, and a variance adaptor conditions a score-based diffusion (SDE) decoder that generates the target mel-spectrogram, vocoded separately with BigVGAN.

Original model and code: [line/promptttspp](https://github.com/line/promptttspp)
