# Chroma

Chroma 1.0 is a real-time end-to-end spoken dialogue model for personalized voice cloning: a Qwen2.5-Omni-3B-based reasoner drives a Llama3-based backbone (16 layers, 2048 hidden size) and a Llama3-based decoder (4 layers, 1024 hidden size) that produce Mimi codec tokens (24kHz) for speech output.

Original model and code: [FlashLabs-AI-Corp/FlashLabs-Chroma](https://github.com/FlashLabs-AI-Corp/FlashLabs-Chroma)
