# VoxInstruct

VoxInstruct is an instruction-to-speech model built on a unified multilingual neural-codec language model: an autoregressive (AR) stage predicts the first codec codebook from a free-form natural-language instruction (with an optional speech prompt), followed by a non-autoregressive (NAR) stage that predicts the remaining codebooks in parallel, decoded to a waveform with a Vocos vocoder.

Original model and code: https://github.com/thuhcsi/VoxInstruct
