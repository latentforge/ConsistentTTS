# F5-TTS

F5-TTS generates speech with conditional flow matching (CFM) over a Diffusion Transformer backbone (DiT, with MMDiT and UNet-T backbone variants also provided) that uses ConvNeXt V2 for text conditioning, with no explicit duration predictor, and Sway Sampling as an inference-time flow-step sampling strategy.

Original model and code: [SWivid/F5-TTS](https://github.com/SWivid/F5-TTS)
