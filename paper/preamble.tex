%
% --- contribution list. IEEE and ICASSP papers set these flush with the text
% block rather than with LaTeX's default itemize indent, which leaves a ragged
% gutter in a narrow column. leftmargin=* removes the extra indent; the label is
% pulled back so the bullets align with the paragraph edge.
%
